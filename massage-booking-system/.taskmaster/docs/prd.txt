# Massage Booking System - Product Requirements Document

## 1. Introduction

This document outlines the comprehensive product requirements for a Massage Booking System, an automated solution designed to streamline operations for a mobile massage business. The system will integrate WhatsApp communication, YClients booking management, and automated notifications to reduce administrative overhead and improve service delivery efficiency.

## 2. Product overview

The Massage Booking System is a comprehensive automation platform that handles the entire booking workflow for a mobile massage service. It processes WhatsApp messages from clients, automatically extracts booking information, creates appointments in YClients, manages payments with VAT calculations, tracks subscription packages, and coordinates notifications between massage therapists and drivers.

## 3. Goals and objectives

### 3.1 Primary goals
- Automate the manual booking process currently handled by administrators
- Reduce administrative workload by 80% through intelligent data extraction and processing
- Ensure accurate VAT calculations and payment tracking
- Streamline communication between clients, therapists, and drivers
- Provide comprehensive subscription package management
- Maintain data integrity across all integrated platforms

### 3.2 Success metrics
- Reduction in manual data entry time from 15 minutes to 2 minutes per booking
- 99% accuracy in data extraction from WhatsApp messages
- Real-time notification delivery to all stakeholders
- Automated VAT calculation compliance
- Complete audit trail for all transactions

## 4. Target audience

### 4.1 Primary users
- **Administrators**: Business owners and office staff who manage bookings
- **Massage Therapists**: Service providers who need location and timing information
- **Drivers**: Transportation providers who need client location details
- **Clients**: End users who book services via WhatsApp

### 4.2 User needs
- **Administrators**: Automated data processing, payment tracking, subscription management
- **Therapists**: Timely location and schedule notifications
- **Drivers**: Accurate location information and timing
- **Clients**: Seamless booking experience via WhatsApp

## 6. User stories and acceptance criteria

### 6.1 WhatsApp booking processing

**ST-101: Client booking via WhatsApp**
- As a client, I want to book a massage by sending a WhatsApp message so I can easily schedule my appointment
- **Acceptance Criteria:**
  - System recognizes booking messages in WhatsApp
  - Extracts client name, service type, preferred date/time, and location
  - Validates all required information is present
  - Sends confirmation message to client
  - Creates appointment in YClients automatically

**ST-102: Template-based booking**
- As a client, I want to use a simple template to provide booking information so the process is consistent
- **Acceptance Criteria:**
  - System provides booking template to clients
  - Template includes fields for name, service, date/time, location
  - AI correctly parses template-based messages
  - Handles variations in template format gracefully

**ST-103: Location processing**
- As a client, I want to share my location via WhatsApp so the therapist can find me easily
- **Acceptance Criteria:**
  - System extracts location links from WhatsApp messages
  - Converts location to readable address format
  - Stores coordinates for mapping purposes
  - Includes location in notifications to therapist and driver

### 6.2 Administrative automation

**AD-101: Automated appointment creation**
- As an administrator, I want appointments to be created automatically so I don't have to manually enter data
- **Acceptance Criteria:**
  - System creates YClients appointments without manual intervention
  - All extracted data is accurately transferred
  - Appointment includes client details, service, timing, and location
  - System handles YClients API errors gracefully

**AD-102: Payment tracking**
- As an administrator, I want to track payment status automatically so I can manage cash flow
- **Acceptance Criteria:**
  - System marks appointments as paid/unpaid
  - Supports cash and card payment methods
  - Automatically calculates and adds 5% VAT
  - Provides payment status dashboard

**AD-103: Subscription management**
- As an administrator, I want to track subscription packages automatically so I can manage client relationships
- **Acceptance Criteria:**
  - System tracks active subscription packages
  - Automatically deducts sessions from packages
  - Alerts when packages are running low
  - Provides subscription status reports

### 6.3 Staff coordination

**SC-101: Therapist notifications**
- As a massage therapist, I want to receive appointment notifications so I know where and when to provide services
- **Acceptance Criteria:**
  - System sends WhatsApp notifications to therapists
  - Notifications include client name, service, time, and location
  - Notifications are sent at appropriate times (e.g., 1 hour before)
  - Includes map link for easy navigation

**SC-102: Driver coordination**
- As a driver, I want to receive location information so I can transport the therapist efficiently
- **Acceptance Criteria:**
  - System forwards location details to drivers
  - Includes timing information for coordination
  - Provides map links for navigation
  - Coordinates with therapist schedule

**SC-103: Status updates**
- As staff, I want to update appointment status so everyone stays informed
- **Acceptance Criteria:**
  - Staff can mark appointments as started, completed, or cancelled
  - Status updates are synchronized across all systems
  - Administrators receive status change notifications
  - Status history is maintained for audit purposes

### 6.4 Error handling and edge cases

**EC-101: Invalid booking data**
- As a client, I want to receive helpful feedback when my booking information is incomplete
- **Acceptance Criteria:**
  - System identifies missing or invalid information
  - Sends helpful error messages requesting clarification
  - Provides examples of correct format
  - Maintains partial booking data for completion

**EC-102: System failures**
- As an administrator, I want the system to handle failures gracefully so business operations continue
- **Acceptance Criteria:**
  - System logs all errors for debugging
  - Provides fallback mechanisms for critical functions
  - Sends alerts to administrators for system issues
  - Maintains data integrity during failures

**EC-103: Manual override**
- As an administrator, I want to manually correct system errors so I can resolve issues quickly
- **Acceptance Criteria:**
  - Administrators can manually edit appointment details
  - System maintains audit trail of manual changes
  - Manual changes are synchronized across all systems
  - Provides clear interface for corrections

## 8. Design and user interface

### 8.1 System architecture

The system will follow a microservices architecture with the following components:

1. **WhatsApp Integration Service**: Handles message reception and parsing
2. **Booking Processing Service**: Manages appointment creation and validation
3. **Notification Service**: Coordinates messaging to staff
4. **Payment Service**: Handles VAT calculations and payment tracking
5. **Subscription Service**: Manages package tracking and alerts
6. **YClients Integration Service**: Handles external API communication

### 8.2 Data flow

1. Client sends WhatsApp message → WhatsApp Integration Service
2. Message parsed → Booking Processing Service
3. Data validated and appointment created → YClients Integration Service
4. Notifications sent → Notification Service
5. Payment and subscription updates → Respective services
6. Status updates synchronized across all systems

### 8.3 Error handling strategy

- **Graceful degradation**: System continues operating even if external APIs fail
- **Retry logic**: Automatic retries for transient failures
- **Fallback mechanisms**: Manual override options for critical functions
- **Monitoring and alerting**: Proactive notification of system issues

### 8.4 Performance requirements

- **Response time**: WhatsApp message processing within 30 seconds
- **Availability**: 99.9% uptime for critical booking functions
- **Scalability**: Support for 100+ daily bookings
- **Data consistency**: ACID compliance for financial transactions

### 8.5 Integration points

- **WhatsApp Business API**: For message reception and sending
- **YClients API**: For appointment and client management
- **Payment gateways**: For payment processing (future enhancement)
- **Mapping services**: For location processing and directions
- **Calendar APIs**: For scheduling integration (future enhancement)
