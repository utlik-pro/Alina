# Massage Booking System

Автоматизированная система управления выездным массажным бизнесом, которая интегрирует WhatsApp, YClients и автоматические уведомления для снижения административной нагрузки.

## 🎯 Цель проекта

Автоматизировать процесс управления массажным бизнесом, который в настоящее время требует ручной работы администратора:
- Получение локации от клиента в WhatsApp
- Пересылка локации массажисту и водителю
- Создание записи в YClients
- Учет оплаты с добавлением 5% VAT
- Управление абонементами

## 🚀 Основные возможности

### 1. Интеграция с WhatsApp
- Автоматическое извлечение данных из сообщений
- Обработка локаций и контактной информации
- Шаблонные диалоги для структурированного общения

### 2. Интеграция с YClients
- Автоматическое создание записей
- Синхронизация статусов
- Управление клиентами и услугами

### 3. Система уведомлений
- Уведомления массажистам о записях
- Пересылка локаций водителям
- Напоминания о предстоящих сеансах

### 4. Финансовый модуль
- Автоматический расчет 5% VAT
- Отслеживание статуса оплаты
- Управление абонементами

## 🛠️ Технологический стек

- **Backend**: Node.js + Express / Python + FastAPI
- **Database**: PostgreSQL
- **Message Queue**: Redis/RabbitMQ
- **APIs**: WhatsApp Business API, YClients API
- **Authentication**: JWT
- **Logging**: Winston
- **Monitoring**: Health checks

## 🚀 Быстрый старт

1. Клонируйте репозиторий
2. Установите зависимости: `npm install`
3. Настройте переменные окружения
4. Запустите базу данных: `docker-compose up -d`
5. Запустите приложение: `npm run dev`
