# Папка Assets

Эта папка содержит файлы ресурсов для системы договоров.

## Файл подписи

### signature_Utlik.png
- **Назначение:** Ваша подпись для автоматического добавления в PDF договоры
- **Формат:** PNG с прозрачным фоном
- **Размер:** Рекомендуется 200x80 пикселей
- **Расположение:** `assets/signature_Utlik.png`

### Как добавить подпись:

1. **Создайте папку assets** (если её нет):
   ```bash
   mkdir assets
   ```

2. **Поместите файл подписи:**
   - Назовите файл: `signature_Utlik.png`
   - Разместите в папке: `assets/signature_Utlik.png`

3. **Проверьте работу:**
   ```bash
   npm run contract:pdf docs/contracts/contract_example_alina.md
   ```

### Требования к файлу подписи:

- **Формат:** PNG
- **Фон:** Прозрачный (для лучшего качества)
- **Цвет:** Черный или темно-серый
- **Размер:** 200x80 пикселей (рекомендуется)
- **Качество:** Высокое разрешение

### Альтернативные форматы:

Система также поддерживает:
- JPG (если нет PNG)
- SVG (автоматически конвертируется)

### Проверка подписи:

```bash
# Проверка наличия файла
ls assets/signature_Utlik.png

# Тест генерации PDF
npm run contract:pdf docs/contracts/contract_example_alina.md
```

### Устранение проблем:

**Если подпись не отображается:**
1. Проверьте путь к файлу
2. Убедитесь в правильном названии файла
3. Проверьте формат файла
4. Убедитесь в правах доступа к файлу

**Если PDF не генерируется:**
1. Установите pandoc: https://pandoc.org/installing.html
2. Установите wkhtmltopdf: https://wkhtmltopdf.org/downloads.html
3. Проверьте наличие файла подписи
