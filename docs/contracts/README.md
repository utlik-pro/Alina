## Быстрый старт

### 1. Создание нового договора

1. Скопируйте `contract_template.md`
2. Переименуйте в `contract_[клиент]_[дата].md`
3. Заполните реквизиты сторон
4. Создайте ТЗ на основе требований клиента
5. Рассчитайте стоимость и сроки

### 2. Нумерация договоров

**Формат:** `ДОГОВОР №[ГОД]-[ПОСЛЕДОВАТЕЛЬНЫЙ НОМЕР]`

**Примеры:**
- ДОГОВОР №2025-001
- ДОГОВОР №2025-002

## Типы проектов и расценки

### Лендинг
- **Срок:** 5-10 дней
- **Стоимость:** 500-1500 руб.
- **Схема оплаты:** 100% предоплата

### Корпоративный сайт
- **Срок:** 15-30 дней
- **Стоимость:** 1500-5000 руб.
- **Схема оплаты:** 50% предоплата + 50% после приемки

### Интернет-магазин
- **Срок:** 20-45 дней
- **Стоимость:** 3000-10000 руб.
- **Схема оплаты:** 30% предоплата + 40% по этапу + 30% после приемки

### Веб-приложение
- **Срок:** 30-90 дней
- **Стоимость:** от 5000 руб.
- **Схема оплаты:** 30% предоплата + 40% по этапу + 30% после приемки

## Процесс работы с клиентом

### 1. Первичный контакт
- Получить описание проекта
- Уточнить бюджет и сроки
- Собрать контактные данные

### 2. Создание ТЗ
- Проанализировать требования
- Создать детальное ТЗ
- Рассчитать стоимость и сроки

### 3. Создание договора
- Использовать шаблон
- Заполнить реквизиты
- Приложить ТЗ

### 4. Согласование
- Отправить договор клиенту
- Внести правки при необходимости
- Подписать договор

### 5. Выполнение работ
- Соблюдать этапы из ТЗ
- Регулярно отчитываться о прогрессе
- Сдавать работу в срок
