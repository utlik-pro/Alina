# ПРАВИЛА СОЗДАНИЯ ДОГОВОРОВ

## Общие принципы

### 1. Структура договора
- Всегда используйте шаблон `contract_template.md` как основу
- Не изменяйте основные разделы без необходимости
- Адаптируйте под конкретный проект

### 2. Нумерация договоров
**Формат:** `ДОГОВОР №[ДДММ]/[ГГ-ММ]/42`

**Структура номера:**
- `[ДДММ]` - день и месяц на момент составления договора
- `[ГГ-ММ]` - год и номер договора в этот день (если в один день два договора, то номер будет 02, 03 и т.д.)
- `42` - фиксированное число (самое главное число во вселенной)

**Примеры:**
- ДОГОВОР № 1604/25-01/42 (16 апреля 2025, первый договор)
- ДОГОВОР № 1604/25-02/42 (16 апреля 2025, второй договор)
- ДОГОВОР № 1501/25-01/42 (15 января 2025, первый договор)

### 3. Датирование
- Дата подписания: текущая дата
- Место подписания: г. Минск (или другой город по согласованию)

## Техническое задание (ТЗ)

### 1. Структура ТЗ
```
1. ОПИСАНИЕ ПРОЕКТА
   - Цели проекта
   - Целевая аудитория
   - Основные функции

2. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
   - Технологии
   - Хостинг
   - Домены
   - SSL-сертификаты

3. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
   - Список страниц
   - Формы
   - Интеграции
   - Админ-панель

4. ЭТАПЫ РАБОТ
   - Планирование
   - Дизайн
   - Разработка
   - Тестирование
   - Запуск

5. КРИТЕРИИ ПРИЕМКИ
   - Функциональность
   - Дизайн
   - Адаптивность
   - Скорость загрузки

6. ПОГРЕШНОСТЬ ОБЪЕМА РАБОТ
   - Допустимая погрешность до 10% от общего объема
   - Учет изменений в требованиях
   - Технические особенности реализации
   - Оптимизация процессов в ходе разработки
```

### 2. Оценка стоимости
**Базовые расценки (2025 год):**
- Лендинг: 500-1500 $
- Корпоративный сайт: 1500-5000 $
- Интернет-магазин: 3000-10000 $
- Веб-приложение: от 5000 $

**Факторы влияния на стоимость:**
- Сложность дизайна
- Количество страниц
- Интеграции с внешними сервисами
- Админ-панель
- Мобильная версия
- SEO-оптимизация

**Важно:** Во всех договорах обязательно включать пункт о допустимой погрешности в объеме выполненных работ до 10% от общего объема проекта. Данная погрешность учитывает возможные изменения в требованиях, технические особенности реализации и оптимизацию процессов в ходе разработки.

## Процесс создания договора

### 1. Подготовка
1. Получить от клиента:
   - Описание проекта
   - Бюджет
   - Сроки
   - Контактные данные

2. Создать ТЗ на основе требований

3. Рассчитать стоимость и сроки

### 2. Создание договора
1. Скопировать шаблон
2. Заполнить реквизиты сторон
3. Указать стоимость и сроки
4. Создать ТЗ
5. Пронумеровать договор

### 3. Согласование
1. Отправить договор клиенту
2. Внести правки по требованию
3. Подписать договор
