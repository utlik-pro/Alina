# ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ СИСТЕМЫ ДОГОВОРОВ

## Быстрый старт

### 1. Создание договора через скрипт

```bash
npm run contract:create
```

Скрипт задаст вам вопросы и автоматически создаст договор с правильной нумерацией.

### 2. Создание договора вручную

1. Скопируйте `contract_template.md`
2. Переименуйте в `contract_[номер]_[клиент].md`
3. Заполните все поля

### 3. Подготовка подписи

**Важно!** Перед генерацией PDF добавьте файл подписи:

1. Создайте папку `assets/`:
   ```bash
   mkdir assets
   ```

2. Поместите файл подписи:
   - Название: `signature_Utlik.png`
   - Путь: `assets/signature_Utlik.png`
   - Формат: PNG с прозрачным фоном
   - Размер: 200x80 пикселей (рекомендуется)

### 4. Генерация PDF с подписью

```bash
npm run contract:pdf docs/contracts/contract_1501_25-01_42_example.md
```

**Требования для генерации PDF:**
- Установленный pandoc: https://pandoc.org/installing.html
- Установленный wkhtmltopdf: https://wkhtmltopdf.org/downloads.html
- Файл подписи: `assets/signature_Utlik.png`

**Альтернативный способ:**
```bash
node scripts/generate_pdf.js docs/contracts/contract_1501_25-01_42_example.md
```

## Часто задаваемые вопросы

### Q: Как изменить шаблон договора?
A: Отредактируйте файл `contract_template.md`

### Q: Как добавить новые типы проектов?
A: Добавьте информацию в `contract_creation_rules.md`

### Q: Как изменить нумерацию договоров?
A: Отредактируйте функцию `generateContractNumber()` в `scripts/create_contract.js`

### Q: Как добавить новые поля в договор?
A: Измените шаблон и скрипт создания договора

### Q: Как изменить подпись в PDF?
A: Замените файл `assets/signature_Utlik.png`

### Q: Почему не генерируется PDF?
A: Проверьте установку pandoc и wkhtmltopdf

### Q: Почему подпись не отображается?
A: Проверьте наличие файла `assets/signature_Utlik.png`

### Q: Какой формат подписи нужен?
A: PNG с прозрачным фоном, размер 200x80 пикселей
