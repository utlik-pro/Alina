1. ОПИСАНИЕ ПРОЕКТА

Разработка комплексной системы автоматизации для массажного салона, включающей интеграцию с WhatsApp для приема заявок, автоматическое создание записей в системе YClients, управление платежами с учетом НДС, систему подписок и автоматические уведомления персоналу.

2. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

  • Backend: Node.js с Express
  • База данных: PostgreSQL
  • Очередь сообщений: Redis
  • API интеграция: YClients API, WhatsApp Business API
  • Аутентификация: JWT-based
  • Логирование: Winston

  • Обработка местоположения
  • Валидация данных

3.2 Интеграция с YClients

  • API интеграция для создания записей
