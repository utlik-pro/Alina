## ПРИЛОЖЕНИЕ №1
### ТЕХНИЧЕСКОЕ ЗАДАНИЕ

#### Massage Booking System - Система автоматизации бронирования массажных услуг

**Проект:** massage-booking-system  
**Дата:** 04.08.2025

**Цель проекта:** Разработка комплексной системы автоматизации для мобильного массажного бизнеса, интегрирующей WhatsApp, YClients и автоматические уведомления.

---

### 1. ОСНОВНЫЕ ФУНКЦИИ СИСТЕМЫ

#### 1.1 Интеграция с WhatsApp
- **Мониторинг сообщений:** Автоматическое отслеживание входящих сообщений WhatsApp
- **Извлечение данных:** Извлечение имени клиента, типа услуги, даты/времени, местоположения
- **Распознавание шаблонов:** Распознавание структурированных шаблонов сообщений
- **Обработка местоположения:** Конвертация ссылок на местоположение в координаты и адреса
- **Валидация данных:** Проверка извлеченных данных перед обработкой
- **Обработка ошибок:** Обработка некорректных сообщений с запросом уточнений

#### 1.2 Интеграция с YClients
- **API интеграция:** Подключение к API YClients для создания записей
- **Создание записей:** Автоматическое создание записей с извлеченными данными
- **Сопоставление услуг:** Сопоставление названий услуг с ID услуг в YClients
- **Управление клиентами:** Создание и обновление записей клиентов в YClients
- **Синхронизация статуса:** Синхронизация статуса записей между системами

#### 1.3 Управление платежами и НДС
- **Расчет НДС:** Автоматическое добавление 5% НДС ко всем ценам услуг
- **Отслеживание платежей:** Отслеживание статуса платежей (оплачено/не оплачено)
- **Методы оплаты:** Поддержка отслеживания наличных и карточных платежей
- **Ручное переопределение:** Возможность ручного обновления статуса платежей
- **Генерация чеков:** Генерация чеков с разбивкой НДС

#### 1.4 Управление пакетами подписок
- **Активация пакетов:** Активация пакетов подписок (например, 10 сеансов)
- **Отслеживание сеансов:** Автоматическое списание сеансов из активных пакетов
- **Мониторинг баланса:** Отслеживание оставшихся сеансов в каждом пакете
- **Уведомления об истечении:** Уведомления администраторов о заканчивающихся пакетах
- **Продление пакетов:** Облегчение процесса продления пакетов

#### 1.5 Система уведомлений
- **Уведомления терапевтам:** Отправка деталей записи массажистам
- **Уведомления водителям:** Пересылка информации о местоположении водителям
- **Доставка через WhatsApp:** Доставка уведомлений через WhatsApp Business API
- **Оптимизация времени:** Отправка уведомлений в оптимальное время (например, за 1 час)
- **Отслеживание подтверждений:** Отслеживание доставки уведомлений и квитанций о прочтении

---

### 2. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

#### 2.1 Технологический стек
- **Backend:** Node.js с Express или Python с FastAPI
- **База данных:** PostgreSQL с правильной индексацией
- **Очередь сообщений:** Redis или RabbitMQ для обработки сообщений WhatsApp
- **API интеграция:** RESTful API для YClients и WhatsApp Business API
- **Аутентификация:** JWT-based аутентификация
- **Логирование:** Структурированное логирование с Winston
- **Мониторинг:** Проверки состояния и мониторинг производительности

#### 2.2 Архитектура системы
- **Микросервисная архитектура** с компонентами:
  - WhatsApp Integration Service
  - Booking Processing Service
  - Notification Service
  - Payment Service
  - Subscription Service
  - YClients Integration Service

#### 2.3 Требования к производительности
- **Время отклика:** Обработка сообщений WhatsApp в течение 30 секунд
- **Доступность:** 99.9% времени безотказной работы для критических функций
- **Масштабируемость:** Поддержка 100+ ежедневных бронирований
- **Консистентность данных:** ACID соответствие для финансовых транзакций
