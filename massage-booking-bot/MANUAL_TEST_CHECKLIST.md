### Проблема: Бот отвечает сразу (нет задержки 7 сек)

**Проверьте логи:**
```bash
grep "добавлено в буфер" bot.log
```

**Если нет таких строк** → буферизация не включена, проверьте код

---

### Проблема: Старые цены

**Проверьте:**
```bash
ps aux | grep "python.*bot.py"
```

**Если PID не 14230** → бот перезапустился, нужен рестарт:
```bash
pkill -9 -f "python.*bot.py"
cd /Users/admin/Alina/massage-booking-bot
.venv/bin/python bot.py > bot.log 2>&1 &
```
