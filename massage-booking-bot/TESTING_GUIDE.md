Убедиться, что бот правильно обрабатывает бронирования, не повторяет вопросы, корректно рассчитывает цены и отправляет полные данные администраторам.

## ✅ ЭТАП 1: Тест массажных услуг (Body massage)

### Что тестируем:
- Выбор услуги "Body massage"
- Выбор длительности (60/90 мин)
- Правильный расчёт цены с VAT
- Отправку локации
- Указание номера виллы
- Выбор времени
- Указание имени
- Формат уведомления администратору

### Шаги теста:

1. **Начать диалог:**
   ```
   /clear
   /start
   ```

2. **Выбрать услугу:**
   ```
   Body massage different techniques
   ```

   ✅ **Ожидаемый результат:**
   - Бот показывает цены:
     - 60 min: 350 AED + 5% VAT = 367.50 AED
     - 90 min: 460 AED + 5% VAT = 483 AED
   - Спрашивает: "Which duration would you like?"

3. **Выбрать длительность:**
   ```
   90 min please
   ```

   ✅ **Ожидаемый результат:**
   - Бот просит локацию: "Could you send your location please?"
   - **НЕ повторяет** вопрос о длительности

4. **Отправить локацию:**
   - Нажать кнопку "📍 Location" в Telegram
   - Отправить текущую локацию

   ✅ **Ожидаемый результат:**
   - Бот спрашивает: "What is your villa or apartment number?"

5. **Указать номер виллы:**
   ```
   villa 25
   ```

   ✅ **Ожидаемый результат:**
   - Бот предлагает слоты: "Tomorrow 10:00 a.m., 12:00 p.m., 4:00 p.m., 7:30 p.m."
   - **НЕ повторяет** вопрос о номере виллы

6. **Выбрать время:**
   ```
   12:00 p.m. is good
   ```

   ✅ **Ожидаемый результат:**
   - Бот спрашивает имя: "What is your good name?"
   - **НЕ повторяет** предложение слотов

7. **Указать имя:**
   ```
   Anna
   ```

   ✅ **Ожидаемый результат:**
   - Бот подтверждает: "Your body massage 90 min is booked at 12:00 p.m. ✅ Thank you, Anna!"
   - **НЕ повторяет** вопрос об имени

8. **Проверить уведомление в группе администраторов:**

   ✅ **Ожидаемое уведомление:**
   ```
   ✅ Бронирование подтверждено!

   👤 Anna
   🛎️ Body massage (90 мин)
   📅 05.11.2025 12:00
   💰 483.00 AED
   📍 Локация на карте
   🏠 villa 25

   ✅ Добавлено в YClients!
   ```

### ❌ Критерии ПРОВАЛА этапа:
- Бот повторяет любой вопрос дважды
- Цена неправильная (не 483.00 AED)
- В уведомлении нет имени, локации или номера виллы
- Бот выдаёт техническую ошибку

### ✅ Критерии УСПЕХА этапа:
- Все вопросы заданы ОДИН раз
- Цена правильная: 483.00 AED
- Уведомление содержит ВСЕ данные
- Нет технических ошибок
