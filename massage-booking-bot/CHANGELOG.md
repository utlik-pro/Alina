## [1.4.0] — 2026-06-02 — Доведение ТЗ до 100%

### Добавлено
- **Планировщик напоминаний** (`services/scheduler.py`, `ReminderScheduler`):
  - Подтверждение за день (FR-3.1) — окно 11:00–12:00 UAE, идемпотентно
  - Пост-сеанс опрос (FR-4) + предложение: следующий сеанс / пакет (новым) / продление (пакетникам)
- **Отмены и переносы** (FR-5.1, 7.2): tools `cancel_appointment` и
  `reschedule_appointment` у агента; обработчики в webhook. По правилу
  безопасности YClients записи правит админ вручную (бот уведомляет).
- **Штрафная система** (`services/cancellation.py`, FR-5.2/5.3): расчёт по
  правилам (>24ч/12-24ч бесплатно; день-в-день — предупреждение; <1ч/мастер
  в пути — transportation charge или списание сеанса), детектор форс-мажора.
- **Учёт пакетов** (`PackageService`): списание сеанса, детект последнего,
  оффер продления.
- **Лист ожидания** (`WaitingList` + `WaitingListService`, FR-7.4): авто-пинг
  при освобождении слота.
- **Instagram-вход** (`services/instagram_client.py` + `/webhook/instagram`):
  квалификация DM → CTA-переход в WhatsApp (deep-link `wa.me`).
- **Уведомления водителю** (`/admin/share-with-driver/{id}`).
- **Приём оплаты** (`services/payment.py`): статус оплаты, реквизиты для
  перевода, `/admin/payment/{id}/paid`; онлайн-провайдер — заглушка.
- **Авто-миграция колонок** (`Database._ensure_columns`) — `ALTER TABLE` для
  новых полей без ручных миграций.

### Изменено
- `Booking`: добавлены `area`, `penalty_amount`, `penalty_reason`,
  `rescheduled_to`, `confirmation_sent_at`, `survey_sent_at`, `package_id`,
  `payment_status`.
- `process_message_with_tools` теперь возвращает `(text, AgentActions)` —
  контейнер для book/cancel/reschedule (1 вызыватель обновлён).
- System prompt: инструкции по вызову tools отмены/переноса.

### Тесты
- +25 тестов (cancellation, scheduler, instagram). **Всего 115 проходят.**
- Починен пред-существующий `test_mock_availability` (форс mock-режима).

## [1.3.0] — 2026-02-25 — Централизация цен + документация

### Добавлено
- **`prices.py`** — единый прайс-лист (70+ услуг, акции, пакеты). Меняешь цену в одном файле — обновляется везде: в ответах бота, в тестах, в upsell-сообщениях
- **`ОТЧЕТ_ДЛЯ_АЛИНЫ.md`** — полный отчёт на русском: состояние бота, прайс, VAT, уведомления, следующие шаги
- **`ПРАВИЛА_ТЕСТИРОВАНИЯ_БОТА.md`** — гайд для Алины и администраторов: 12 тестовых сценариев, 12 запрещённых фраз, таблица оценки качества
- **`REPORT_FOR_ALINA.md`** — английская версия отчёта с чек-листом тестирования

### Изменено
- **`agents/booking_agent.py`** — system prompt генерируется динамически из `prices.py` (метод `_build_system_prompt()`)
- **`bot.py`** — ~40 хардкодов цен заменены на `get_price()` из `prices.py`
- **`services/booking_flow.py`** — SERVICE_CATALOG строится из `prices.py` через `_build_service_catalog()`
- **`services/follow_up.py`** — upsell-сообщения с динамическими ценами через `_build_upsell_recommendations()`
- **`config.py`** — модель по умолчанию обновлена с `gpt-4o-mini` на `gpt-5-mini`
- **`.env.example`** — обновлена модель на `gpt-5-mini`

### Тесты
- Все 5 тестовых файлов обновлены: хардкод цен заменён на `get_price()` из `prices.py`
- Все **92 теста проходят** после всех изменений

### Исправлено
- Цена body massage 90min: 460 → **480 AED** (была рассинхронизация)
- Цена body+face combo: 590 → **650 AED** (была рассинхронизация)

## [1.2.0] — 2026-02-24 — WhatsApp, YClients, Follow-up система

### Добавлено
- **WhatsApp Cloud API** интеграция (мок-режим) — webhook, отправка/приём сообщений
- **YClients API** интеграция (мок-режим) — проверка слотов, создание бронирований
- **Follow-up система** — автоматические напоминания потеряшкам (5 попыток: 1ч → 4ч → 24ч → 48ч → 72ч)
- **Message buffering** — ждёт 20 секунд тишины перед ответом (клиенты пишут несколько сообщений подряд)
- **Upselling** — рекомендации дополнительных услуг после бронирования
- **Анализ WhatsApp чатов** — обучение бота на реальных диалогах Алины
- **92 автоматических теста** (e2e, critical scenarios, unit)

### Изменено
- System prompt переписан на основе реальных WhatsApp-диалогов
- Добавлен список из 12 запрещённых фраз (бот не должен звучать как робот)
- VAT: cash = 0%, bank transfer = +5%
- Разбивка длинных ответов на 2-3 отдельных сообщения (через `---MESSAGE_SPLIT---`)

## [1.0.0] — 2025-11-04 — MVP Release

### Добавлено

#### Telegram Bot с AI агентом
- GPT для общения с клиентами
- System prompt на основе реальных WhatsApp диалогов
- Поддержка английского языка

#### База данных SQLite
- Таблицы: `clients`, `messages`, `bookings`, `dialog_sessions`, `packages`
- Автоматическое создание клиента при `/start`
- Сохранение истории переписки
- Tracking состояния диалога
- Сохранение медицинских заметок

#### Telegram Group Notifications
- Новые клиенты
- Заявки на бронирование
- Подтверждённые бронирования
- Отмены
- Потерянные клиенты (нет ответа >1 часа)
- Медицинские противопоказания

#### Бизнес-логика бронирования
- Расчёт VAT 5%
- Проверка доступности слотов (mock)
- Сбор информации: услуга → длительность → локация → слот → имя
- Подтверждение бронирования

### Исправлено
- Issue #1: JSON Serialization Error — datetime конвертация в ISO string
- Issue #2: Bot не показывал цены — обновлён system prompt
- Issue #3: Bot не распознавал выбор длительности — добавлены паттерны
- Issue #4: Bot запрашивал локацию дважды — флаг `has_location`
- Issue #5: Bot предлагал слоты повторно — распознавание выбора времени
- Issue #6: Bot повторно запрашивал имя — явное указание в контексте GPT
- Issue #7: Отсутствие цен на некоторые услуги — полный прайс в prompt

### Технические детали
- Python 3.13, aiogram 3.15+, SQLAlchemy 2.0, OpenAI API
- Команды: `/start`, `/clear`, `/status`
