# Тестирование бота с правильной логикой VAT

## Изменения

### ✅ Исправлено:

1. **Цены для клиента** - показываются БЕЗ VAT
2. **Добавлен вопрос о способе оплаты** перед подтверждением
3. **Расчет VAT** зависит от способа оплаты:
   - 💵 **Наличные (cash)**: цена БЕЗ VAT (350 AED)
   - 🏦 **Перевод (transfer)**: цена + 5% VAT (367.50 AED)
4. **Уведомления в группу** показывают правильную цену с деталями

## Как тестировать

### 1. Запуск бота

```bash
cd massage-booking-bot

# Активируем виртуальное окружение
source .venv/bin/activate  # macOS/Linux
# или
.venv\Scripts\activate  # Windows

# Запускаем бота
python run.py
```

### 2. Создание тестовой группы

1. Создайте группу в Telegram
2. Добавьте бота в группу
3. Получите `CHAT_ID` группы (можно использовать @getidsbot)
4. Добавьте в `.env`:
   ```
   ADMIN_GROUP_CHAT_ID=-1001234567890
   ```

### 3. Тестовый сценарий

#### Сценарий 1: Оплата наличными

1. Клиент: `/start`
2. Бот: Приветствие с услугами
3. Клиент: `Body massage`
4. Бот: **ДВА сообщения**:
   - Сообщение 1: Описание техник массажа
   - Сообщение 2: Цены БЕЗ VAT (350 AED, 460 AED)
5. Клиент: `60 min`
6. Бот: Запрашивает локацию
7. Клиент: Отправляет геолокацию
8. Бот: Запрашивает номер виллы/апартаментов
9. Клиент: `Villa 123`
10. Бот: Предлагает слоты
11. Клиент: `10:00 a.m.`
12. Бот: Запрашивает имя
13. Клиент: `Alina`
14. Бот: Запрашивает способ оплаты
15. Клиент: `cash`
16. Бот: Подтверждает бронирование
17. **В группу приходит**: "💵 350.00 AED (наличные, без VAT)"

#### Сценарий 2: Оплата переводом

Повторите сценарий 1, но на шаге 15:
15. Клиент: `bank transfer`
16. **В группу приходит**: "🏦 367.50 AED (перевод: 350.00 + 17.50 VAT)"

## Troubleshooting

### Бот не спрашивает способ оплаты

- Проверьте что имя клиента уже сохранено в контексте
- Проверьте логи: `grep "payment_method" logs/bot.log`

### Цена неправильная в группе

- Проверьте что `booking.payment_method` сохранен в БД
- Проверьте что `calculate_total()` вызывается после установки `payment_method`

### База данных ошибка "no such column: payment_method"

- Выполните миграцию (см. выше)
- Или удалите и пересоздайте БД
